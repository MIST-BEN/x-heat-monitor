> 面向网络工程师与创作者的 **X (原 Twitter) 帖子热度时序差分检测插件**。  
> 默认以 **3 分钟** 为周期高速采样，直接在推文旁边实时标出周期增量与自看到起的累计总增量！

---

## 🌟 核心特性 (v1.3.0)

### 1. ⏱️ 灵敏度升级：默认 3 分钟检测周期
- 采样周期从 5 分钟缩短为 **3 分钟（可自定义 1/2/3/5/10/15 分钟）**，大幅减少等待时间，更快捕捉新帖初期的流量脉冲！
- 页面扫描频率优化至每 6 秒探测一次，滚动页面或切换标签即刻同步。

### 2. 🎯 帖子旁内嵌药丸胶囊（周期增量 | 累计总增量双显）
- 在每条推文底部操作工具栏（点赞、转发按钮右侧）直接呈现双显徽章：
  - `⚡ 3m: +18阅 | 总: +18阅`：清晰呈现近 3 分钟跳变与看后总增长。
  - `🔥 3m: +2赞 +30阅 | 总: +5赞 +120阅`：爆款流量快速标红警示。
  - `☕ 3m: 0 | 总: +18阅`：近 3 分钟平稳，但自首次刷到已有增长。
  - `⏱️ 初始记录中 | 基准已锁定`：初次捕获，初始基准永久留存。

### 3. 🔍 完整时序四列表格 & 翻折防遮挡优化
- 悬浮展开 320px 全宽明细卡片，清晰对比：
  - `近 3 分钟增量` vs `首次看到至今总增量` vs `当前实际总量`。
- **智能边缘翻折**：当推文位于页面顶部或屏幕边缘时，弹窗自动向下翻折展开，杜绝内容被浏览器顶部遮挡。
- **即时反馈重置基准**：点击 `[ 🔄 重置基准 ]` 按钮可一键将当前数据设为新起点，附带即时高亮反馈。

### 4. 🛡️ DOM 原生完整计数提取（支持 title 属性深度解析）
- 即使页面上的大数字显示为缩写（如 `1.2K`），插件会自动深入解析 HTML 的 `title="1,248"` 与 `aria-label` 属性，最大化恢复个位数精度。

---

## 🚀 安装与更新

1. 打开浏览器扩展管理页 `chrome://extensions/`。
2. 找到 **X Heat Pulse** 卡片，点击右下角 **🔄 重新加载（Reload）**。
3. 刷新你的 [x.com](https://x.com) 页面，尽享 3 分钟高灵敏度监控！
